# Content Workspace

These folders are reserved for future creative assets and records. The repository is currently primarily an editorial doctrine.

- **ideas/**: human situations, hypotheses, premises.
- **drafts/**: AI or human written candidate posts. Not approved.
- **approved/**: copy explicitly approved by the owner. Not necessarily published.
- **published/**: exact published copy and metadata/links when available.

Do not silently promote files between stages. See workflows/final-review.md.

## Suggested Markdown metadata
For future content records, fields may include: slug, subject, emotional_register, archetype, status, created_at, approved_at, published_at, source_url, editorial_notes. The actual post copy should be separately identifiable and preserved exactly.

## File naming
Use ISO date when useful plus a concise slug, for example YYYY-MM-DD-quiet-courage.md. Do not create duplicate candidate posts merely because multiple render sizes exist.

## Important distinction
The gold-standard archive is **not** the approved folder. It lives in standards/gold-standards.md and remains unpopulated until the owner supplies actual breakout posts.
